### 💬 Python Comments

Comments are used to explain code, make code easier to read, and prevent code from running 
during testing. A comment starts with `#`, and Python ignores comments when executing the 
code. Comments can be written on a separate line or at the end of a code line. Anything 
after `#` on the same line is treated as a comment. Adding `#` before a code line prevents 
that line from running.

### 📝 Multiline Comments

Python has no special syntax for multiline comments. `#` can be used at the beginning of 
each line to create a multiline comment. Triple quotes (`""" """`) can be used as a 
multiline string when they are not assigned to a variable, but they are not actual comment 
syntax.

### 📌 Key Concepts

| Term | Definition |
|---|---|
| **Comment** | Text added to code to **explain it or make it easier to understand**, which 
Python ignores during execution. |
| **Multiline String** | A **string that can contain text across multiple lines** using 
triple quotes (`""" """`). |
