### 🧾 Python Statements

A computer program is a list of instructions called statements that are executed by the 
computer and in Python statements usually end when the line ends so semicolons are not 
required and multiple statements are normally written on separate lines and executed one by 
one in the same order they appear while semicolons can optionally separate multiple 
statements on the same line they are rarely used because they make the code harder to read 
and if two statements are written on the same line without a newline or semicolon Python 
will give a syntax error.

### 📌 Key Concepts

| Term | Definition |
|---|---|
| **Statement** | An **instruction in a program** that tells the computer what to do. |
| **Semicolon (`;`)** | A **symbol that can be used to separate multiple statements on the 
same line** in Python, but it is rarely used. |
| **Newline** | The **end of a line of code**, which normally separates statements in 
Python. |
