Python introduction:

Python:

Python is a popular programming language created by Guido van Rossum and released in 1991

It is used for:

Web development (server-side)

Software development

Mathematics

System scripting



Python Capabilities:

Python can create web applications on servers

It can work alongside other software to create workflows

It can connect to database systems

It can read and modify files

It can handle big data and perform complex mathematical operations

It is used for rapid prototyping and production-ready software development


Python Advantages:

Python works on different platforms such as:

Windows

Mac

Linux

Raspberry Pi


It has a simple English like syntax

It allows developers to write programs using fewer lines of code than some other programming 
languages

It uses an interpreter so code can be executed as soon as it is written making prototyping 
faster

It supports different programming approaches:

Procedural programming

Object-oriented programming

Functional programming



Python Versions and Development Tools:

Python 3 is the latest major version used in this tutorial

Python can be written using a text editor

It can also be written using an IDE (Integrated Development Environment)

Examples of Python IDEs include:

Thonny

PyCharm

NetBeans

Eclipse


IDEs are especially useful for managing large collections of Python files


Python Syntax:

Python was designed for readability

Its syntax has similarities to English and is influenced by mathematics

Python uses new lines to complete commands instead of the semicolons or parentheses commonly
 used in other programming languages

Python uses indentation (whitespace) to define the scope of:

Loops

Functions

Classes


Other programming languages often use curly brackets {} to define scope.
