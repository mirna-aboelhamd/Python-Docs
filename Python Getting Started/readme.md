## 📌 Key Concepts

| Term | Definition |
|---|---|
| **Python** | A **high-level interpreted programming language** used to create
applications, automate tasks, analyze data, and build many types of software. |
| **`.py Extension`** | The **file extension used for Python source code files**, which 
tells the computer that the file contains Python code. |
| **`print()` Function** | A **built-in Python function used to display output** such as
text, numbers, or the result of an operation on the screen. |
| **`python --version` Command** | A **command used in the command line to display the
installed Python version**, helping you check which version is available on the computer. |
| **`sys.version` Attribute** | An **attribute that provides information about the Python
version and interpreter**, and it can be accessed after importing the `sys` module. |
| **Command Line** | A **text-based interface where you can enter commands directly to the
computer**, including commands to run Python programs. |
| **`>>>` Prompt** | The **symbol displayed by the Python interpreter when it is ready to
receive and execute a Python command**. |
| **`exit()` Function** | A **function used to leave and close the Python interactive 
command line**. |
