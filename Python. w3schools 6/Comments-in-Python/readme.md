
Python Comments
Comments are used to:

Explain code

Make code easier to read

Prevent code from running during testing

A comment starts with #

Python ignores comments when executing the code

Comments can be written:

On a separate line

At the end of a code line

Anything after # on the same line is treated as a comment

Adding # before a code line prevents that line from running

Multiline Comments:

Python has no special syntax for multiline comments

Use # at the beginning of each line to create a multiline comment

Triple quotes (""" """) can be used as a multiline string when they are not assigned to a
variable

Triple quotes are not actual comment syntax; they are multiline strings
