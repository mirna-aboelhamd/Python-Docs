### 🖨️ Python Output / Print

The `print()` function is used to display text or output on the screen and it can be used as 
many times as needed with each call printing on a new line by default text must be written 
inside either double quotes or single quotes while numbers are written without quotes and 
numbers can also be used directly in mathematical operations inside `print()` text and 
numbers can be displayed together by separating them with a comma and the `end` parameter 
can be used to print multiple outputs on the same line.

### 📌 Key Concept

| Term | Definition |
|---|---|
| **`end` Parameter** | A **parameter used with `print()` to control what is printed at the 
end of the output**, such as keeping multiple outputs on the same line. |
