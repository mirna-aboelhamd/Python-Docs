Python Getting Started:

1 - Python is an interpreted programming language

2 - Python files use the .py extension

3 - The print() function displays output

4 - The python --version command shows the Python version

5 - The sys.version attribute shows Python version information
 
import sys	print(sys.version)

6 - Python can run directly from the command line

7 - The >>> symbol means the Python interpreter is ready

8 - The exit() function closes the Python command line
