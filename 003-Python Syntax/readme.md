### 📝 Python Syntax

Python Syntax means the rules for writing Python code correctly. Python code can be executed 
directly in the Command Line. Python code can also be written in a `.py` file and executed
through the Command Line.

### 📐 Python Indentation

Python uses indentation, which means spaces at the beginning of a code line to define a
block of code. Unlike many other programming languages, indentation in Python is essential.
At least one space is required, with four spaces being the most common choice. The same
number of spaces must be used within the same block; otherwise, Python will give an error.

### 📌 Key Concepts

| Term | Definition |
|---|---|
| **Python Syntax** | The rules for writing Python code correctly. |
| **Code Block** | A group of related lines of code that are treated as one section. |
| **Readability** | How easy code is to read and understand. |
| **Syntax Error** | An error caused by writing code incorrectly according to Python’s
syntax. |
