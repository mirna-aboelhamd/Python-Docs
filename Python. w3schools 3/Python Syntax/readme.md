
Python Syntax :

Python Syntax means the rules for writing Python code correctly
Python code can be executed directly in the Command Line
Python code can also be written in a .py file and executed through the Command Line

 Python Indentation :
Python uses indentation which means spaces at the beginning of a code line to define a block
of code and unlike many other programming languages where indentation is mainly used for
readability indentation in Python is essential and the amount of spaces can be chosen by 
the programmer but it must be at least one space with four spaces being the most common
choice and the same number of spaces must be used within the same block otherwise Python
will give an error
