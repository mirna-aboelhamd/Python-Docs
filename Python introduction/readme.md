# 📖 Python Introduction

## Python

Python is a popular programming language created by **Guido van Rossum** and released in 
**1991**.

It is a simple and easy-to-learn language that can be used for many different types of
projects.

Python is commonly used for:

- Web development (server-side)
- Software development
- Mathematics
- System scripting

---

## ⚙️ Python Capabilities

Python can be used to:

- Build web applications and run them on servers
- Work with other software to create useful workflows
- Connect to databases
- Read and edit files
- Work with large amounts of data
- Perform complex mathematical operations
- Quickly build prototypes and develop real-world applications

---

## 💡 Python Advantages

One of the main advantages of Python is that it works on many different platforms, including:

- Windows
- macOS
- Linux
- Raspberry Pi

Python also has:

- Simple and easy-to-read syntax
- Less code compared to some other programming languages
- An interpreter that runs the code directly
- Support for different programming styles:
  - Procedural Programming
  - Object-Oriented Programming
  - Functional Programming

---

## 🛠️ Python Versions and Development Tools

**Python 3** is the main version used in this tutorial.

Python code can be written using a simple text editor or an **IDE (Integrated Development
Environment)**.

Some popular Python IDEs are:

- Thonny
- PyCharm
- NetBeans
- Eclipse

IDEs are especially helpful when working with large projects that contain many Python files.

---

## 📝 Python Syntax

Python is designed to be easy to read and understand.

Its syntax is similar to the English language and also has some ideas inspired by
mathematics.

Python uses **new lines** to finish commands instead of using semicolons or parentheses like
some other programming languages.

Python also uses **indentation (whitespace)** to organize code and define blocks such as:

- Loops
- Functions
- Classes

For example, some programming languages use curly brackets `{}` to define blocks of code,
while Python uses indentation instead.

## 📚 Key Concepts

| Term | Definition |
|---|---|
| **Workflow** | A series of steps that are done in a specific order to achieve a result. |
| **Prototyping** | Creating a simple first version of a program to test an idea before 
building the final version. |
| **Production-ready Software Development** | Building software that is stable, secure, and 
ready to be used in real-world situations. |
| **Syntax** | The rules that tell us how to write code correctly so the programming
language can understand it. |
| **Interpreter** | A program that reads and runs code step by step while the program is 
running. |
| **Compiler** | A program that converts the whole source code into an executable form
before the program runs. |
| **Procedural Programming** | A way of writing programs by organizing the code into steps
and procedures. |
| **Object-Oriented Programming (OOP)** | A way of organizing code around objects that
contain related data and functions. |
| **Functional Programming** | A programming style that mainly uses functions to perform
operations and tries to avoid changing data and program state. |
| **Indentation** | The spaces at the beginning of a line of code. In Python, indentation is
used to organize code and define code blocks. |
